## Navigation & Categories

1. **Category 1: Sentence Mechanics & Syntactic Compression** (9 skills) — Micro-level syntactic discipline, locomotive syntax, active verbs, preposition compacting.
2. **Category 2: Paragraph Cohesion & Information Flow** (6 skills) — Topic-Comment elaboration, linear relay linking, cathedral taxonomy, roadmap previews.
3. **Category 3: Macro Architecture, Proposals & PR Structuring** (6 skills) — 3-part proposal engine, cold-reader audit, skim-test outliner, stakeholder calibration.
4. **Category 4: Code Walkthroughs, Explanation & Review Etiquette** (7 skills) — Uneven U explainer, watchmaker model, Bilbo principle, peer etiquette.
5. **Category 5: System Grounding, AI Boundaries & Architecture Guardrails** (9 skills) — Read-only vault isolation, substance-first refactoring, 3D grounding.
6. **Category 6: Cognitive Load, Tone & Reader Alignment** (11 skills) — Decoupled reader delivery, zero meta-discourse, calibrated tone, cinematic scaffolding.
